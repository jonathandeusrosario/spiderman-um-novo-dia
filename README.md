# 🕷️ Spider-Man: Um Novo Dia

Landing page inspirada no filme **Spider-Man: Um Novo Dia**, desenvolvida como meu primeiro projeto web.

Este projeto foi criado com o objetivo de colocar em prática meus primeiros conhecimentos de **HTML, CSS e JavaScript**, explorando também animações, efeitos visuais, manipulação do DOM e integração com bibliotecas externas.

> 🚀 Este foi meu primeiro projeto de desenvolvimento web, então ele representa principalmente meu processo de aprendizado e evolução.

## 🌐 Demonstração

🔗 **Acesse o projeto:**  
https://jonathandeusrosario.github.io/spiderman-um-novo-dia/

## 📸 Sobre o projeto

A proposta foi criar uma experiência visual inspirada nos sites promocionais de filmes da Marvel, utilizando uma interface moderna e animações para apresentar o universo de Spider-Man.

O projeto possui:

- 🎬 Hero section inspirada em uma página promocional de filme
- 🕷️ Identidade visual inspirada no Spider-Man
- 🎞️ Trailer integrado ao site
- 🎭 Seção de elenco interativa
- 🖼️ Transições entre imagens dos personagens
- ✨ Animações utilizando GSAP
- 📜 Scroll com efeitos e animações
- 🎨 Máscaras e recortes utilizando CSS/SVG
- 📱 Estrutura responsiva para diferentes tamanhos de tela
- 🎥 Player de vídeo personalizado

## 🛠️ Tecnologias utilizadas

### HTML5
Utilizado para estruturar todo o conteúdo da página.

### CSS3
Utilizado para:

- Layout
- Responsividade
- Animações
- Transições
- Gradientes
- Máscaras e `clip-path`
- Posicionamento dos elementos
- Efeitos visuais

### JavaScript
Utilizado para adicionar interatividade e controlar:

- Animações
- Interações do elenco
- Player de vídeo
- Alteração de conteúdo
- Eventos da página
- Manipulação do DOM

### GSAP

Utilizado para criar as animações e transições da página.

Bibliotecas utilizadas:

- GSAP
- ScrollTrigger
- ScrollSmoother
- SplitText

Durante o desenvolvimento deste projeto, utilizei o **Antigravity** como ferramenta de apoio para desenvolvimento e resolução de problemas no código.

A ferramenta foi utilizada principalmente para:

- Auxiliar na escrita e organização do código

- Sugerir melhorias
- Ajudar na implementação de funcionalidades

Apesar do auxílio de IA, o projeto também fez parte do meu processo de aprendizado e experimentação com desenvolvimento web.
